# Esri 11.5 documentation

Links for ArcGIS Enterprise 11.5. They use Esri's standard 11.5 paths and couldn't be opened from where this guide was written, so labels in your UI may differ slightly. If you find an Esri link elsewhere with `latest` in the address, change it to `11.5` (or `3.5` for Pro) to match the portal.

| Step | Topic | Link |
|---|---|---|
| 1 | Share a web feature layer from ArcGIS Pro | [Share a web feature layer](https://pro.arcgis.com/en/pro-app/3.5/help/sharing/overview/share-a-web-feature-layer.htm) (ArcGIS Pro 3.5, the release paired with Enterprise 11.5) |
| 2 | Views | [Create hosted feature layer views](https://enterprise.arcgis.com/en/portal/11.5/use/create-hosted-views.htm) |
| 2 | View settings | [Edit a hosted feature layer view definition](https://enterprise.arcgis.com/en/portal/11.5/use/set-view-definition.htm) |
| 2 | Editing settings | [Manage hosted feature layer editing](https://enterprise.arcgis.com/en/portal/11.5/use/manage-editing-hfl.htm) |
| 2 | Who can see and edit what | [Data access and editing](https://enterprise.arcgis.com/en/portal/11.5/use/data-access-and-editing.htm) |
| 6 | Survey123 on Enterprise | [Use Survey123 with ArcGIS Enterprise](https://doc.arcgis.com/en/survey123/get-started/survey123withenterprise.htm) |

Field Maps, Survey123 and Arcade docs on doc.arcgis.com aren't versioned per Enterprise release. Where they mention a feature, the **Check in 11.5** notes in each step flag what to confirm on your portal.
